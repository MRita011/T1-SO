## Versão sequencial

A versão sequencial realiza a contagem de objetos em uma matriz binária utilizando conectividade 8.

### Compilação

No Linux, macOS ou WSL:

```bash
gcc -std=c89 -Wall -Wextra -pedantic src/conta-objetos-sequencial.c -o sequencial
```
e depois:

```
./sequencial
```
